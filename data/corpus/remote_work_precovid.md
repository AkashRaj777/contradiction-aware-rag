# Remote Work Policy (Pre-COVID Baseline)

**Document ID:** remote_work_precovid  
**Effective:** 2019 — March 2020 (historical reference)

## Hybrid allowance
Under the **pre-COVID remote work policy**, employees could work remotely up to **8 days per month** (not per week). There was no "core in-office day" requirement.

## Approval
Manager approval was required via email; no formal HR ticket.

## Default arrangement
Remote work was **not** the default; office attendance was expected unless an exception was granted.

## Full-time remote
**Permanent full-time remote work** was generally **not permitted** except for pre-approved field roles.
