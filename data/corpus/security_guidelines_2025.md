# Security Guidelines (2025)

**Document ID:** security_guidelines_2025  
**Effective:** January 2025

## Biometric authentication
**Biometric authentication is required** for all **high-privilege accounts** (admin, production deploy, finance systems).

## MFA — fingerprint
**Fingerprint-based authentication** may be used as a **secondary** MFA factor only, **not** as the sole primary factor for high-privilege accounts.

## Security incident escalation
**Escalation path for reporting a security incident:**
1. Employee reports to manager within 1 hour  
2. Manager opens ticket with **Security Operations (SecOps)**  
3. SecOps engages **CISO office** for P1/P2 within 4 hours  

## VPN
Remote access requires **GlobalProtect VPN** (see remote work policy).

## Policy rationale
**Reason for tightening security guidelines in the new policy:** rise in credential theft, mandate for zero-trust access, and audit findings from 2024 penetration test.
